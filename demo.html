No-install evaluation

Run the insurance workflow with seed data or your own local file.

This demo runs the same scoring engine as the production app (v1.1): CSV import with renewal and consent columns, editable custom fields, missing-field imputation, LTV scoring, visual or JSON risk rules, a renewal worklist and board, consent-aware lists, CSV export, and campaign simulation.

Evaluation flow
Real data replaces the seed sample.

Upload a policyholder CSV in Import & health, work the renewal board, edit custom field cells like a small sheet, then switch between the visual rule builder and the Rules JSON editor. CSV rows hold people; rules JSON holds conditions and actions. The browser saves demo state locally until you reset it.

Inline editing is live in Book, Import & health, and list previews. Every change is one undo step.
